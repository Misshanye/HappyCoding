在线版增量更新：提交本节课学习日志（2026-11-03）

安装：
将本包中的 index.html、learning-log.js、learning-log-config.js、local-learning-log.js
上传到原 GitHub Pages 网页文件所在目录，覆盖同名文件，并保留原运行环境、analytics 配置、素材和其余文件。
这是增量更新包，不能只靠本包独立运行；无需改动 Umami 网站编号或原统计账号。
部署完成后按 Ctrl+F5，顶部应出现绿色“提交本节课学习日志”按钮。
本包未替你推送或发布到 GitHub。

学生使用：
1. 正常进入课堂、运行代码，本机浏览器会自动记录学习操作。
2. 结束本次练习后，点击“提交本节课学习日志”。
3. 网页先整理当前日志并发起下载“学习日志.zip”，然后在新标签页打开：
   https://v.wjx.cn/vm/wayfzFB.aspx#
4. 在问卷中选择刚下载的压缩包，填写并提交。
如果新标签页被拦截，点击页面显示的“打开学习日志提交问卷”。
附件选择和最终提交仍由学生在问卷中完成，不会自动填写、自动上传或自动提交问卷。

日志存在哪里：
提交前，日志保存在当前浏览器、当前网站来源的 IndexedDB 本地数据库中。
待写事件另用 localStorage 短暂保存，写入成功后才清除暂存；页面刷新可恢复。
本地档案与 Umami 待传队列相互独立，Umami 接收成功后仍保留本地记录。
不需要额外服务器或数据库账号，也不会因此删除你原有的 Umami 历史记录。
浏览器清除网站数据、无痕模式关闭、机房系统还原或存储配额不足仍可能影响保存。
网页顶部会提示保存问题；出现提示时保留当前页面，及时尝试导出。
未点击按钮前，不会在电脑的“下载”文件夹生成 ZIP 文件。

下载范围与命名：
每次点击都会重新生成 ZIP，包含当前浏览器在本网站保存的各次访问记录，每次访问一份 CSV。
CSV 文件名为 online_完整随机编号_月日_时分秒.csv，日期按电脑本地时区生成。
刷新沿用当前访问编号；重新打开网页或新开标签页生成新编号，不要求连续编号。
CSV 内时间字段使用 UTC ISO 格式，便于跨时区分析；同时记录 session_start 与 event_id。
浏览器不提供 MAC 地址，本功能不会查询或记录 MAC/IP。
导出不会删除本地记录，因此可以重复提交，增加收集容错。
浏览器通常把 ZIP 放进“下载”文件夹，也可能询问保存位置；不能由网页强制保存到桌面。
重复下载时浏览器可能给文件名加序号，选择本次刚下载的版本即可。
网页只能确认已发起下载，不能验证浏览器最终保存完成；上传前确认压缩包已下载完。

记录内容：
模块、关卡、任务/案例、Python/C、任务/自由编程模式、运行序号与独立事件编号。
运行开始、运行成功/错误/停止、关键报错类型/摘要/行号、任务判定、重置与任务/模式切换。
编辑行为以停顿合并为一次操作，不记录具体编辑内容或按键。
记录前台、活动估计、空闲与经过时长；它们不是专注程度的测量。
不保存完整代码、输入内容、输出全文、完整变量快照或身份姓名。
无报错的运行与任务通过是两种事件，不能混为一谈。
新增模块只要继续使用统一运行与任务框架，就能带入相应信息。

统计保持：
原有 Umami 访问/运行等统计及其网站编号继续使用，小猫原调查问卷入口保留。
本地档案支持在远程统计不可用或 DNT/GPC 禁止远程统计时继续保存教学日志，不会绕过远程统计禁用设置发送数据。
本地采集可通过 learning-log-config.js 的 localArchive 设置单独关闭。
本更新不会把完整本地档案自动传给 Umami；教师通过学生在问卷中上传的文件获取档案。
更新前已经上报且未保留在本地档案的旧事件，无法凭本更新补回到 ZIP 中。

分析提示：
每一行是一条事件，每份 CSV 是一次访问，不是一名学生的永久编号。
多个压缩包可能包含相同事件，合并时按 event_id 去重。
learning_time 行内是该时间片的毫秒值，应仅按此类事件求和统计用时；其他事件的 elapsed_ms 可能是单次运行耗时。
ZIP 内附日志说明，CSV 使用 UTF-8 BOM，支持 Excel；文本做公式转义处理。

已用 Python zipfile 实际解包生成的 ZIP，验证 CRC、中文文件名、CSV 编码和错误记录；生成 ZIP 不依赖额外网络/CDN。
